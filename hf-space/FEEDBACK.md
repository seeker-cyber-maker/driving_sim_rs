# Feedback report template

This form is a local template. It does not submit a message or upload files.
Use the public issue form at https://github.com/seeker-cyber-maker/aits-driving-around/issues/new
to report a problem. Review every attachment before posting. The issue tracker is
for product reports; do not include confidential material.

- App URL:
- Build ID (from an exported run or batch receipt):
- Browser and version:
- Operating system:
- CPU or GPU:
- Track name, network shape, and sensor/output types:
- Exact steps to reproduce:
- Expected behavior:
- Observed behavior:
- Did a retry work? Did the page confirm server-copy deletion?

Attach the exported receipt only after reviewing it. It contains settings, file hashes,
metrics, and build identity; no network weights or job access keys. Batch receipts also
contain your recipe and batch names. Redact those names if they are private.
Do not attach tokens, job keys, private networks, proprietary tracks, or unrelated logs.
A cropped screenshot and a generated example are usually sufficient.

For a GPU rejection, include the visible error and cleanup message; never paste a token.
